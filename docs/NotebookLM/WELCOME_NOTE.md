# Welcome to LDAP-2FA on Kubernetes (EKS)

Welcome. This project delivers centralized identity with LDAP, 2FA (TOTP
and SMS), and full automation on EKS via Terraform and GitOps: four-layer
deployment, EKS and LDAP stack, cross-account design, GitOps and the 2FA
app, and end-state operations. Content is grounded in this project's docs.
